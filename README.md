# 🚀 My Personal Portfolio

Welcome to the repository for my personal portfolio website! This site serves as a digital home for my work, sharing my technical background, core skills, and live application links with future teammates and employers.

### 🌟 Key Features
* **Fully Responsive Design:** Tailored carefully to look beautiful on smartphones, tablets, and desktop monitors.
* **Live Project Showcases:** Direct links to interactive web applications I have built.
* **Contact Integration:** A dedicated form allowing recruiters to message me or schedule meetings easily.

### 🛠️ Built With
* **Frontend:** React, TypeScript, HTML5, CSS3, Tailwind CSS
* **Hosting/Deployment:** GitHub Pages / Vercel
